Open Jenkins

Jenkins runs separately from this library app. Start the Jenkins service, then open Jenkins at http://localhost:8080 on the computer where it is installed.

In Jenkins, select New Item, choose Pipeline, then under Pipeline script from SCM enter your GitHub repository and set the script path to Jenkinsfile. Save, then select Build Now for a manual run. Scheduled builds and GitHub polling are configured in the Jenkinsfile.

If Jenkins is not installed yet, see the setup steps in the project README.
